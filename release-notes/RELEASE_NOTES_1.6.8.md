# OC Remote v1.6.8 - Release Notes

Patch release focused on consistent Material theming and typography across light, dark, dynamic, and AMOLED modes.

## Highlights

- Unified status bars, navigation bars, top app bars, and screen backgrounds around the active Material surface color.
- Improved session cards and server screens so light, dark, and dynamic themes use consistent container tones without overly bright dark-mode surfaces.
- Standardized dialog title sizing across server, session, terminal, and local runtime dialogs.
- Improved local runtime launch options on smaller screens and large font sizes with scrollable content and theme-aware surfaces.
- Preserved true-black surfaces and subtle borders for AMOLED mode.
- Repaired malformed French placeholders in chat, OAuth, and notification text.
